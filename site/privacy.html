隐私说明

Owl Drop 无需账号，不含广告、分析或追踪 SDK。开发者不收集或接收通过本应用传输的文件、文件名、局域网地址或传输记录。

你选择的文件通过 macOS 系统隔空投送发送。iPhone 发送到 Mac 时，接收确认、联系人限制和文件保存由系统处理。

局域网接收由你的 Mac 临时运行 HTTP 服务，文件直接从手机浏览器传到 Mac，不经过开发者的云端。HTTP 不加密，仅应在可信局域网开启。持有当前二维码或上传地址的人可在开启期间上传文件。关闭接收或退出应用后，当前地址失效。

上传文件保存在“下载 / Owl Drop”，重名文件不覆盖。文件由你自行管理和删除。应用仅在本次运行中保留最近接收列表，不把历史记录上传至服务器。选择文件、下载文件夹和局域网权限仅用于上述功能。

如主动通过邮件联系支持，你提供的联系方式和问题描述仅用于回应和处理请求。请勿发送密码或不必要的私人文件。本说明可能随功能变更更新，日期会同步调整。

使用支持

联系：acyg6789@163.com

  • Mac 到 iPhone：选择或拖入文件，点击“隔空投送…”，在系统窗口选择接收设备。
  • iPhone 到 Mac：在手机分享菜单中选择隔空投送；确认 Mac 的系统接收设置。
  • 安卓到 Mac：两端连接同一可信 Wi-Fi，开启局域网接收，扫码后从浏览器相册或文件选择器上传。无需安卓客户端。
  • 无法连接：检查局域网权限、防火墙和访客网络隔离。换网络后关闭再重新开启接收。
  • 浏览器路径只支持手机向 Mac 发送；单文件最多 2 GB。当前应用界面为简体中文，要求 Apple Silicon Mac、macOS 13 或更高版本。

Privacy

Owl Drop requires no account and contains no advertising, analytics or tracking SDKs. The developer does not collect or receive transferred files, filenames, local network addresses or transfer records.

Files you select are sent through the macOS AirDrop service. For iPhone-to-Mac AirDrop, macOS handles recipient permissions, confirmation and file destinations.

Local receiving temporarily runs an HTTP server on your Mac. Files travel directly from the phone browser to the Mac, without a developer-operated cloud intermediary. HTTP is unencrypted: use it only on trusted local networks. Anyone holding the current QR code or upload link can upload while receiving is enabled. Stopping receiving or quitting invalidates that link.

Uploaded files are saved in Downloads / Owl Drop without overwriting existing files. You manage and delete them yourself. The recent-receipts list exists only for the current app run and is not uploaded. File selection, Downloads and local network permissions support only these functions.

If you contact support by email, information you voluntarily provide is used to respond to your request. Do not send passwords or unnecessary private files. We may update this policy when features change and will update its effective date.
